# AI-Use Summary

During the development of this midterm project, AI was utilized responsibly as a technical assistant:
- **Error Solving:** Assisted in resolving PyTorch tensor shape mismatches and memory layout errors (such as replacing `.view(-1)` with `.reshape(-1)` for non-contiguous tensors).
- **Code Structuring:** Provided syntax suggestions for setting up the PyTorch data-batching generators and multi-head attention blocks.
- **Independence:** All conceptual designs, evaluation code, hyperparameter tunings, analysis, and written reflections were independently understood, verified, and structured.
